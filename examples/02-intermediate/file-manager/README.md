# File Manager CLI

Aplikasi file manager sederhana untuk operasi file dan direktori.

## Fitur

- List files dan direktori
- Buat direktori baru
- Copy file
- Move/rename file
- Delete file/direktori
- Show file info
- Search files

## Cara Menjalankan

```bash
go run main.go
```

## Contoh Penggunaan

```text
=== FILE MANAGER ===
Current directory: /home/user
1. List Files
2. Create Directory
3. Copy File
4. Move File
5. Delete File
6. File Info
7. Search Files
8. Change Directory
9. Exit
Choose option (1-9): 1
```

Project ini mengajarkan:

- File I/O operations
