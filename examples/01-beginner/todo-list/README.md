# Todo List CLI

Aplikasi todo list sederhana untuk mengelola tugas harian.

## Fitur

- Tambah tugas baru
- Lihat semua tugas
- Tandai tugas sebagai selesai
- Hapus tugas
- Simpan data ke file JSON

## Cara Menjalankan

```bash
go run main.go
```

## Contoh Penggunaan

```text
=== TODO LIST ===
1. Tambah Tugas
2. Lihat Tugas
3. Selesaikan Tugas
4. Hapus Tugas
5. Keluar
Pilih menu (1-5): 1
Masukkan tugas: Belajar Golang
Tugas berhasil ditambahkan!
```

## Pembelajaran

Project ini mengajarkan:

- Struct dan methods
- Slice operations
- File I/O dengan JSON
- Control flow dan loops
- Error handling
