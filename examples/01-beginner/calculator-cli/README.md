# Calculator CLI

Aplikasi kalkulator sederhana menggunakan command line interface.

## Fitur

- Operasi matematika dasar (tambah, kurang, kali, bagi)
- Input validasi
- Error handling untuk division by zero
- Menu interaktif

## Cara Menjalankan

```bash
go run main.go
```

## Contoh Penggunaan

```
=== KALKULATOR SEDERHANA ===
1. Penjumlahan
2. Pengurangan
3. Perkalian
4. Pembagian
5. Keluar
Pilih operasi (1-5): 1
Masukkan angka pertama: 10
Masukkan angka kedua: 5
Hasil: 10 + 5 = 15
```

## Pembelajaran

Project ini mengajarkan:

- Basic input/output
- Control flow (switch case)
- Function creation
- Error handling
- Loop untuk menu interaktif
